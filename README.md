# Road-Traffic-Accidents

## Business Problem
This project analyzes road traffic accident data to
identify dangerous driving conditions and help an
autonomous vehicle company prioritize data collection.

## Dataset
Addis Ababa Road Traffic Accident Dataset

## Business Questions
1. Which lighting conditions have the highest
   share of serious or fatal crashes?
2. Does weather affect crash severity?
3. Which junction types have the highest severity rates?
4. What hours have the most crashes?
5. Which weather conditions have the fewest
   recorded crashes?
